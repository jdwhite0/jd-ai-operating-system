# os/ — Your personal operating system

This folder is **yours**. After the short interview (`ONBOARDING/INTERVIEW.md`), your LLM fills brain + daily state here.

## Layout

```
os/
├── brain/          # Who you are, priorities, domains
├── systems/        # Rules every AI follows
├── daily/          # today.md — the heartbeat
├── projects/       # Active work (create as needed)
├── media/          # Media workspace (create as needed)
├── resources/      # Reference libraries (create as needed)
├── automations/    # Scripts (create as needed)
└── backups/        # Snapshots you choose to keep
```

## Operate loop

```
BOOT.md → os/daily/today.md → os/systems/ → os/brain/ → act → report
```

## Optional: Obsidian

Open this `os/` folder as an Obsidian vault for a human-friendly browse UI. Obsidian is recommended, not required.
