# Philosophy

1. **Files you own** — memory and rules live on your machine / your fork.  
2. **Any mind can drive** — the OS is model-agnostic.  
3. **Teach, don’t overwhelm** — one phase at a time; narrate every unlock.  
4. **Sequence over guesswork** — installs are encoded; agents don’t invent stacks.  
5. **Human gates stay human** — accounts, 2FA, starring, OS approvals.  
6. **Agent web needs a real browser** — EgoLite for authenticated work.  
7. **Personal ≠ company dump** — public OS serves individuals; private infra stays private.

The goal: a non-developer completes first-run without a founder sitting at the keyboard.
