# INTERVIEW.md — Short onboarding questions

Ask these **once** during first run (Phase D). Prefer one message with the full list.  
After answers, write `os/brain/identity.md`, `os/brain/priorities.md`, and `os/daily/today.md`.

Keep it light. No interrogation.

---

## Questions (8 required + 2 optional)

1. **What should I call you?**  
2. **In one sentence, what’s your main goal this season?**  
3. **Confirm your device:** macOS / Windows / Linux (LLM should auto-detect and ask to confirm).  
4. **Which AI(s) will you use with this OS?** (Claude, ChatGPT, Gemini, Cursor, Ollama, other)  
5. **How do you spend most days?** student / creator / founder / employee / other  
6. **Top 3 priorities right now** (short bullets)  
7. **What does “this worked” look like in 30 days?**  
8. **Any boundaries I must respect?** (e.g. no late-night work, don’t touch finance files, ask before deleting)

Optional:

9. **Timezone** (e.g. America/New_York)  
10. **Bias for help:** more writing / more code / more ops & organization / balanced  

---

## After answers — write files

### `os/brain/identity.md`

Fill name, one-liner, roles, vision, boundaries from answers. Leave values/principles lightly sketched if they didn’t provide them.

### `os/brain/priorities.md`

Map Q6 into P0/P1. Cap at 3 P0s.

### `os/daily/today.md`

- State: `Planning` for day one  
- Focus line: their season goal  
- Top 3: first actions toward priorities  
- AI log: date + model + “completed onboarding interview”

### Confirm to user

> Your personal OS is ready in the `os/` folder. I’ll read `today.md` first every session. Want to do the first real action now?
